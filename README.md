# Modulez Player

Modulez Player is a Linux player for tracker modules, chiptunes, MIDI, audio and video. This repository hosts the [official website](https://dasteele-ctrl.github.io/modulez-player/).

## 1.8.7 — The RMF Update

Play original Beatnik RMF files directly with NeoBAE and the bundled Beatnik Standard v1.1.1 Uncompressed soundbank. In **Browse Music**, play or queue WebTV tracks, search the SoundMusicSys folders, or open a Headspace album. You can listen to one song or save the album ZIP to Downloads.
